## Official failures

Three scenarios were officially scored as failures:

- `repeated_error_stops_loop`
- `max_five_steps_explained`
- `holdout_v051_request_after_blocked_path`

The first two remain historical Runtime Regression / Real Model Evaluation responsibility mismatches: the scripted expected path requires deliberate repeated failure or max-step exhaustion, while the real model completes the available task early. Their official scores are not rewritten.

The one substantive model failure was `holdout_v051_request_after_blocked_path`. After path reachability recovered, the model repeated `move_to(player)` rather than returning to the door and selecting `ask_through(topic=request)`, ending in `LOOP_DETECTED`.

No further repair of the door micro-world is authorized for v0.5.1.

## Execution retrospective

Before the formal model calls, the first automation attempts failed during offline verification. The causes were operational rather than NPC behavior defects:

- a reused/copied virtual environment retained an old import path and bytecode state;
- `scripts/verify_v051.sh` invoked a bare system `python` rather than the selected virtual-environment interpreter;
- failed preflight attempts left lock-state cleanup to manual intervention.

After selecting the correct virtual-environment interpreter and clearing stale bytecode, the formal model run executed once. The result manifests record one formal episode per scenario and zero provider retries.

The archival patch fixes `verify_v051.sh` so every Python command uses one explicit interpreter, disables user site-packages, validates the imported module path and version, and clears only ignored source-tree bytecode before verification.

## Decision

v0.5.1 is accepted as the frozen local-model reliability baseline:

- local Qwen3-4B Q5 capability validated on cloud GPU;
- deterministic factual renderer validated;
- dialogue/world-action isolation validated;
- all protocol, grounding and safety gates passed;
- RTX 4060 and UE5 coexistence remain unvalidated.

The next engineering milestone is v0.6 Headless Game Bridge. The 30-Episode result must not be rerun or overwritten to improve its score.
