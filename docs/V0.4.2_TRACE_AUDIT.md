## Root causes identified from per-Tick traces

1. Model-authored report predicates and sources did not match the Executor's hidden vocabulary.
2. `ask_through` ignored its free-text topic and always returned an identity claim.
3. Evaluator completion conditions included hidden derived fields, notably conflict status.
4. Exact-parameter loop detection missed semantically identical rephrased questions.
5. Full observation history was resent each Tick and dominated prompt cost.
6. Provider invalid-argument errors lacked enough bounded evidence for diagnosis.
7. Several original scenarios are runtime fault-injection tests rather than fair real-model tasks.

## v0.4.3 response

The repair is structural rather than scenario-specific: stable fact IDs, enumerated topics, explicit completion progress, semantic no-progress detection, compact history and separate holdout scenarios.
