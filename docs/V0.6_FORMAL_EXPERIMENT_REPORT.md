## 实验结果复现

本实验使用专用的形式化运行框架（`run_formal_v2.sh`），确保：

1. 首次模型调用前强制验证 159/159 pytest + 确定性 Gate（Golden digest、回归 20/20、离线 Soak 10K/10K/100）
2. 模型和运行时二进制 SHA 锁定
3. 原子式 formal claim 防止二次运行
4. 20 场景和 Soak 各只运行一次
5. 全部原始证据归档到私有存储

### 有界状态实现

状态有界性通过以下组件实现：

- `active_actions`：只包含 REQUESTED / ACCEPTED / STARTED 状态的动作
- `terminal_action_cache`：FIFO 有界缓存（生产默认 256），保存终态 fingerprint 用于幂等判断
- `request_cache`：FIFO 有界（生产默认 2048）
- `report_history` / `heard_event_history`：有界 FIFO（生产默认 128）
- JSONL Trace 保留完整永久历史
