## Architecture boundaries

- **Deterministic only:** P0–P5 contain no LLM calls or random behaviour
- **Append-only occurrence:** Events are immutable; memory and records are versioned
- **Role-private observation:** Characters see only what they should
- **Atomic acknowledgement:** NameRecord admission + ConnectionVersion + ManifestationDelta commit as one Trace record or none
- **Replay-verified archives:** Save/load cycles produce identical state digests
- **Bounded caches:** Lineages, versions, forgetting events, acknowledgements, belief queries, manifestation audits all have strict maximum sizes
